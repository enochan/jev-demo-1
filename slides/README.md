# Jev 勉強会スライド

`index.html` をブラウザで開いて利用できます（外部ライブラリへの依存はありません）。

- ← → / スペース / クリック：スライド移動
- `f`：全画面表示
- URL に `#3` を指定すると3枚目のスライドから開きます。

デモの動作環境は別 PR（`demo/`）に含まれています。

公開版：`.github/workflows/pages.yml` により https://enochan.github.io/jev-demo-1/ で公開されます（Settings → Pages の Source を「GitHub Actions」に設定後に有効化されます）。
